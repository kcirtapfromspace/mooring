# Mooring 0.3.0 preview 39 — Edge to edge

On a viewing Mac with a camera notch, full screen while controlling now uses the row beside the camera. The sharing Mac's menu bar moves up into that row, its bottom level with the notch's, and nothing below it is hidden. The sharing Mac keeps the span behind the notch clear, so its app menus and status items flow around it and menus on both sides open on the sharing Mac. **Settings → Viewing → Use the space beside the camera** turns this off; it is on by default and applies while **Match Shared Screen to This Mac** is on. The viewer asks for the gap through a new session capability, so both Macs need this preview. With an older sharing Mac, full screen stays below the notch as before.

The remote pointer now reaches every edge. The viewer divided pointer positions by the picture's width, while the sharing Mac maps the last position to its last point, so the pointer stopped about a point short of the right and bottom edges and a Dock hidden on the right never appeared. The first and last points now map exactly to the remote screen's edges. In full screen, moving past the picture holds the remote pointer at that edge, however fast the move. In a window, moving across the black bars does the same. Clicks in the bars are still ignored.

⌘-Tab and other system shortcuts reach the sharing Mac only when Mooring is allowed in Accessibility on the viewing Mac. When it isn't, control now starts with a notice over the picture, once per window and with **Open Accessibility Settings…**, including when the footer is hidden. The session log says whether shortcuts are captured.

Local validation covers Rust, including the new menu bar messages in each direction and with and without the capability; native input checks for edge mapping, full-screen edge holding and the notch arithmetic; native media and session suites; encrypted loopback streaming; the packaged CLI; and the app build. On a notched MacBook Pro, a harness drove the real viewer into full screen with a synthetic remote screen, and a capture of the top row matched pixel for pixel. The menu bar gap was set and removed on a real menu bar. A real two-Mac session with this preview on both Macs, long app menus, and status items that already reach the notch remain separate acceptance checks.

Use **Check for Updates…** on each Mac, or download the ZIP. Updates install while idle. Apple silicon and macOS 14 or later; Developer ID signed, notarized and stapled. All tests, builds, signing and packaging run on the local Mac. GitHub Actions remains disabled.
